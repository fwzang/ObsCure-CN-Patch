## 已确认的行为模式（本包的定义特征）

**切屏 → 黑屏 → 文字出现才放行**：

- `version.dll` = clearflash8，其 CAVE_P 在 Reset 后调用 `Clear` 保持黑屏，
- 直到「连续 3 帧命中字体绑定」判定文字绘制已稳定（D_STABLE=1）才停止 Clear，
- 效果：切屏期间不出现竖条纹/半成品帧，画面与文字一起出现；
- 无 `swap_mode.txt` → 判据为 mode A（`tex == g_fontTex`）；
- 本构建为 nolog/nodump：不生成 `__RUNTIME__` 日志与贴图 dump。

**后续任何 hook 改动都必须保留这一行为**，否则视为回归。
