## 一、中台是什么

把「已破解的引擎知识 + 已验证的产线 + 已验证的质量门」固化成平台，
二代汉化不再从零破解，只做**单产线增量变更 → 单产线校验 → 合并基线 → 全量回归 → 检查点发布**。

### 五层架构

```
┌─────────────────────────────────────────────────────────────┐
│ L5 交付层  检查点 / md5 清单 / 交接包 / 回滚链                  │
├─────────────────────────────────────────────────────────────┤
│ L4 质量层  四套测试矩阵 + 全树 diff + 实机验收判据              │
├─────────────────────────────────────────────────────────────┤
│ L3 产线层  文本产线 │ 贴图产线 │ 字库产线 │ 数据包产线 │ 安装器产线 │
├─────────────────────────────────────────────────────────────┤
│ L2 资产层  TSV 语料 │ 官方中文贴图 │ 字体源 │ zh_en.lng 基线    │
├─────────────────────────────────────────────────────────────┤
│ L1 知识层  HVP 格式 / lng 结构 / 图集双通道 / 字形表 / hook 机制 │
└─────────────────────────────────────────────────────────────┘
```

## 二、L1 知识层（全部已验证，直接引用）

| 事实 | 结论 | 出处 |
|---|---|---|
| HVP 目录项 | `[u32 BE nameLen][name][25B meta]`；资源 N 数据由**前一项** meta 描述；zlib 裸流 | 引擎分析_汉化中台 |
| en.lng 结构 | 24B 头 + `[L][body][6B meta]`，末条无 meta；type=1 = UTF-16LE 宽字符 | 同上（100% round-trip） |
| 英文基底差异 | Steam 原版 en.lng = **149,816 B**；ODE 英文版 = **150,600 B**（+784B） | v1.00 加强版实测 |
| 地图贴图 | `datapack._common/maps_pc/`：BMP = zlib 压缩的 24bpp；TGA = 32bpp BGRA + v2 footer | 本轮实测 |
| 图集双通道 | RGB=可见内容、alpha=形状标记；新字须米白×alpha/255 预乘 + int() 截断 | 引擎分析_汉化中台 |
| 字形表 | 10B/条 `[u16 码点][x][y][w][adv]`；u16 原生支持中文；**只追加不重排** | 同上 |
| hook 契约 | version.dll 代理换 512×128 GPU 纹理；17 导出；禁 GetTexture 查询；改 exe 必须新增独立 PE 节 | 同上 |
| 安装机制 | `obscure-hvp.exe extract→替换→create` 全量重建，确定性可复现（同输入同输出） | v1.00 E2E 实证 |

## 四、L3 产线层（五条产线，各自的输入/工具/输出/门）

### P1 文本产线（改译文）

```
batch_XXX.tsv（修订）→ rebuild_en.py → zh_en.lng（新 md5）
                          ↓
                 记录级校验：3078 条闭环 / type=1 中文数 / 控制码标记数与 pristine 一致
```
- 工具：`hzp_tools/` 下 rebuild 系脚本（二代需按第二节规范重新归档 canonical 版）
- 门：lng 解析 round-trip + 与装机版 diff 条数 = 修订条数

### P2 贴图产线（改地图/UI 贴图）

```
官方中文 PNG 或 PS 成品 → convert_map_tex.py（BMP，保留原头只换像素）
                        → convert_tga.py（TGA，保留 18B 头 + 26B footer，只换 BGRA）
                          ↓
                 逐件校验：魔数/尺寸/位深/解码像素与源 PNG 逐字节一致
```
- 已装机 33 件清单：`installer_v100/payload/maps_pc/MAP_TEX_LIST.txt`
- 二代补充（需PS 320 件）：PS 规范 = 同尺寸 RGB PNG（无 alpha 要求的 BMP 走 24bpp；TGA 走 RGBA 且 alpha 与原版一致）

### P3 字库产线（加字符）

```
charset 增量 → make_atlas 系脚本 → big_atlas_c.raw + table_c.bin
                          ↓
                 铁律：表只追加；原区 150 字形 + 17 图标 RGBA 全通道照搬；预乘口径 int() 截断
                 门：装机实测新字符渲染 + full_verify 全包 diff
```

### P4 数据包产线（合并进 datapack）

```
原版基底（23ef7697 或 ecaabade）+ zh_en.lng + maps_pc/33 件
   → obscure-hvp.exe extract → 替换 _texts/en.lng + _common/maps_pc/33 件 → create
   → datapack 新 md5（现基线 58599296 = Steam 基底；bfe692ba = ODE 基底）
```
- 幂等判据：en.lng md5 + 33 贴图 md5 全量比对
- 门：再解包全树 diff（除目标文件零差异）+ 目标文件逐件核验

### P5 安装器产线（出包）

```
payload/（8 基础 + 33 贴图 + zh_en.lng + obscure-hvp.exe + 免责声明）
   → make_manifest_diff.py → INSTALLER_MANIFEST.json
   → PyInstaller 骨架（系统 Python312，--icon 游戏图标）
   → append_payload（只能执行一次！）
   → 四套测试 + 真实冒烟
```
- 加强版 = P5 + ODE 链（3 xdelta + data/ 16 件）；汉化层与精简版同模板
- 门：见 L4

## 七、二代汉化流程（SOP）

### 7.1 触发场景与路径

| 场景 | 路径 | 预估面 |
|---|---|---|
| 译文修订/补译（201 空 + 54 遗留） | P1 → P4 → P5 | 文本链 |
| 贴图补充（需PS 320 件） | P2 → P4 → P5 | 贴图链 |
| 字体扩展（新字符/新字号） | P3 → P4 → P5 + 实机 | 字库链 |
| 游戏/ODE 更新 | 重新提取基底 → 全产线重跑 + 测试矩阵 | 全链 |
| hook 演进（c94+） | 源码取回 → 编译 → 17 导出校验 → 装机四件替换 | hook 链 |

### 7.2 标准六步（任何场景都走这六步）

1. **取源**：从 L2 资产层拉真源（TSV/贴图/字体），禁止从装机目录反向提取当源
2. **单产线变更**：只动一条产线，产出新 md5，登记《变更单》（改了什么、为什么、影响面）
3. **单产线校验**：该产线的门（P1 条数/P2 逐件/P3 实测/P4 全树 diff）
4. **合并基线**：校验过才替换 L2 基线文件；旧基线移入 `archive/` 不删除
5. **全量回归**：按 §五 测试矩阵跑；真实环境冒烟
6. **检查点发布**：固化检查点 → 更新交接包 + 交接说明 + 最新进度 → 通知可发布

### 7.3 增量铁律（二代不可破坏，全部来自实战教训）

1. **字形表只追加**，禁全量重排（重排=全部字形错位）
2. **译文控制码标记数必须与 pristine 一致**（修复过的崩溃教训）
3. **贴图替换保留原文件结构**：BMP 留 54B 头、TGA 留 18B 头 + 26B footer，只换像素区，长度守恒
4. **改包只走 obscure-hvp create**，禁手工改目录/偏移（缩包/移动数据会破坏后续资源绝对偏移）
5. **payload 结构变更后必须重跑 make_manifest**（v1.00 踩过：manifest 陈旧→幂等失效）
6. **append_payload 只能对新鲜 PyInstaller 骨架执行一次**（重复追加之体积翻倍）
7. **单变量 rollout**：一次只改一条产线；装机验证前一步绿了才下一步
8. **任何变更配回滚**：脚本 + 备份目录，先于变更执行
9. **构建 GUI 安装器必须用系统 Python312**（managed 3.13 无 tkinter）
10. **发布包绝不预置** `versionproxy.log` / `x_hook.log` / `c87_paths.txt`（OPEN_EXISTING 补丁对已存在文件失效）
