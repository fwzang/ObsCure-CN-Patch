## 2. 安装

把 4 个文件**全部**覆盖到游戏根目录：

```
<Steam>\steamapps\common\Obscure\
```

已存在同名文件的一律覆盖。这是 `version.dll` 代理注入方案，**不能只换部分文件**——hook、图集、字符表、数据包是配套的。

安装后目录里还应存在（由本补丁自动使用）：

- `cachpack.hvp`（游戏原文件，未改动）
- `swap_mode.txt`（可选，A/B 切屏调试开关；删掉即默认模式）

## 3. 卸载 / 回滚

1. 移除 `version.dll`（代理失效，游戏回到英文原版）。
2. 如需恢复汉化前的资源，从备份还原 `datapack.hvp` / `big_atlas_c.raw` / `table_c.bin`（原版值见第 5 节）。

游戏主程序 `Obscure.exe` **未被修改**，无需还原。

## 4. v1 修复了什么

| 问题                        | v1 行为                                                      |
| :------------------------ | :--------------------------------------------------------- |
| Alt-Tab 切屏后画面出现**条纹闪帧**   | 设备 Reset 后由代理主动 Clear 遮罩，直到游戏真正恢复绘制 → 闪帧不可见                |
| 首次启动文字**空白约 2 秒**         | 启动稳定等待窗由 150 帧缩短至 30 帧（日志 `[D2S] confirm@98 f=128`）        |
| 启动加载期被误遮黑                 | 新增"曾绑字体"跨 Reset 持久标志，启动期不 Clear                            |
| 暂停菜单切屏后**画面已出、文字空 2.6 秒** | Clear 停黑判据升级为"连续 3 帧都在绑定字体纹理"（稳定绘制才放行），重建期全程遮黑 → 画面与文字同时出现 |

安全兜底：任一判据异常时，Clear 最长 3.5 秒后强制放行，绝不会永久黑屏。

## 6. 已知限制

- **主菜单窗口不支持外部注入按键**（含 PostMessage 模拟）。这是游戏自身特性，与本补丁无关；请人工操作。
- **不要用"最小化→还原"切屏**。该操作会让 D3D9 设备进入 lost 状态导致白屏崩溃；请用 **Alt-Tab**。这是游戏原生行为。
- 汉化覆盖 2823 / 3078 条（91.7%）；剩余 201 条为空、54 条为 PS2/Xbox 平台遗留。
- 仅适配 D3D9 硬件加速。
