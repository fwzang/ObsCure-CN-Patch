# 已知行为说明 · 文字不显示

> 面向玩家。版本：2026-10-11>   
> 本文档说明一个**已知行为**及其恢复方法，不影响存档与游戏进度。

---

## 【已知行为：切屏后文字消失】

**现象**：切屏（Alt+Tab 切出再切回）后，游戏内文字可能消失。

**恢复方法**：进入游戏设置界面 → 再返回，文字即恢复。

**说明**：这是已知行为，不影响存档和进度。

---

## 【同一行为：启动后菜单文字偶发不显示】

**现象**：游戏启动后，主菜单文字**偶发**不显示（不是每次，约几次里出现一次）。

**恢复方法**：同样——进入游戏设置界面 → 再返回，文字即恢复。  
（也可以重启游戏，或等游戏自身某次刷新画面时自动恢复）

**说明**：与上一条是**同一个原因**，不影响存档和进度。

---

## 为什么会这样（一句话）

游戏在**切换画面模式**（切屏/启动）时，会重新初始化显示资源。此时中文的字体数据需要等游戏**下一次绘制文字界面**才会重新加载。

- 平时的画面刷新（移动光标、开关暂停菜单）**不会**触发这个重新加载
- **切换到一个新界面**（如"游戏设置"）**会**触发 —— 所以进一次设置就能恢复

## 恢复方法图示

```
文字消失
   ↓
切换到任意一个「新界面」
   ↓
文字出现 ✓
   ↓
返回上一界面（文字保持）
```

**记住一句话就够了：看不到字，就进一次设置再返回。**

## 可用的恢复动作（实测清单）

| 动作                        | 能否恢复     | 说明             |
| ------------------------- | -------- | -------------- |
| 进入「游戏设置」                  | ✅ **有效** | 最稳妥，推荐         |
| 进入「键位设置」等设置子界面            | ✅ 有效     | 同上原理           |
| 进入「读取存档」列表                | ✅ 有效     | 同上原理           |
| **点击「退出游戏」弹出「确定要退出吗」确认框** | ✅ **有效** | **不确认即可返回，安全** |
| 移动光标（方向键）                 | ❌ 无效     | 只是重绘当前画面       |
| 按 ESC 开关暂停菜单              | ❌ 无效     | 同上             |
| 仅切屏后等待                    | ❌ 无效     | 不会自动恢复         |

**原理**：游戏在**切换到一个新界面**时，会重新初始化界面资源、重新绘制文字 —— 这时中文字体数据才会被重新加载。而"重绘当前画面"（移动光标、开关菜单）不会触发这个过程。

## 更进一步的技术说明（供维护者参考）

**根因链条**：

```
切屏（Alt+Tab） → 游戏重置显示设备（D3D9 Reset）
   → 汉化字体补丁被安全撤回（避免参数与纹理错配产生竖条）
   → 游戏重建字体资源（已确认：资源重建成功）
   → ★ 但游戏不会立即重新绘制文字 → 不绑定字体纹理
   → 字体补丁无法恢复 → 中文不显示
   → 直到游戏「绘制一个新的文字界面」（如设置界面）→ 绑定字体纹理 → 补丁恢复
```

**为什么不能由补丁侧自动恢复**：  
恢复的前提是"确认字体纹理已绑定到绘制管线"，而这个确认动作在当前实现中不可用：

- 主动查询绑定状态 → 会造成资源引用泄漏 → 触发旧问题（切屏白屏）
- 归还引用 → 资源被提前销毁 → 触发设备丢失白屏
- 跳过确认直接强制绑定 → 可能与游戏自身的绑定冲突，产生竖条/画面异常

因此选择"**如实记录为标准已知行为**"，而非引入新的不稳定因素。

**相关日志特征**（用于诊断，如日后需要再现）：

```
[RESET] 真正的 Reset 返回 hr=0x0 (成功)          ← 切屏成功
[RESET] ★ 抓到新字体纹理 tex=... → 等绑定看门狗确认    ← 字体资源已重建
[FONT-CONFIRM] 组1登记 ...                        ← 但未绑定
（此时文字不显示）
[3B] SetTexture 已确认字体纹理绑定 -> 开闸并立即打补丁   ← 进入设置界面后恢复
```

## 附：本次调查中确认的其它结论

| 项                           | 结论                  |
| --------------------------- | ------------------- |
| 纯 Alt-Tab 后等待               | ❌ 不会自动恢复            |
| 按方向键（移动光标）                  | ❌ 不会恢复              |
| 按 ESC（暂停菜单）                 | ❌ 不会恢复              |
| **进入另一个界面（设置 / 键位 / 读档列表）** | ✅ **恢复**            |
| **进入「退出游戏」确认框**             | ✅ **恢复**（不确认即可安全返回） |
| 恢复后返回上级界面                   | ✅ 文字保持              |
| 再次切屏                        | ❌ 又消失（需再切换一次界面）     |

## ⚠️ 另一项已知风险（与本文档无关，但需知悉）

**请避免在「游戏设置」界面停留时进行切屏操作（Alt+Tab）**。

- 该场景下曾出现过**游戏白屏、系统崩溃**的极端情况
- 在其它界面（主菜单、游戏中）切屏目前观察正常
- 该问题正在调查中，暂定规避措施：**切屏前先退出设置界面**

（此项与"文字不显示"是两个独立问题，请勿混淆）
