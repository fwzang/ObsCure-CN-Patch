## 2. 安装流程（安装器做什么）

**汉化核心（4 件套，缺一不可）**

1. 直写 3 文件：`version.dll`（028ec9a8）+ `big_atlas_c.raw`（12879fb3）+ `table_c.bin`（9cf562f5）
2. 本地重建 datapack：`extract 原版 → 替换 _texts\en.lng（中文译文）+ 替换 _common/maps_pc 33 件贴图 → create`  
   （需约 1.4GB 临时空间，全程约 5 秒；重建结果与开发机装机态逐项一致）

**宽屏补丁（3 件，独立可选）**：`dinput8.dll` + `scripts/obscure.asi` + `scripts/main.patch`

**免责声明**：payload 内置 `免责声明.txt`，安装时释放到游戏根目录（版权归育碧软件/Ubisoft 及原开发组所有；本补丁仅供学习研究使用）。

**备份/卸载**：备份直接放 `游戏目录\_obscure_backup\`（**无时间戳子目录**，只备份首次、不覆盖），  
记录 `_added_files.txt`；卸载 = 从该目录逐项覆盖回游戏目录 + 删新增文件 + 删除备份目录，回到安装前状态。

## 4. 重新构建（在交接机上）

```bash
cd hzp_tools/out/installer_v100
# venv 必须用【自带 tkinter 的 Python】（系统 Python312；managed 3.13 无 tkinter → GUI 起不来）
"D:/Python/python.exe" -m venv inst_env312    # 或本机 C:/Users/.../Python312/python.exe
./inst_env312/Scripts/python.exe -m pip install pyinstaller pillow
./inst_env312/Scripts/python.exe make_app_icon.py                      # 游戏图标
./inst_env312/Scripts/python.exe installer_src/make_manifest_diff.py   # manifest（41 arcs）
./inst_env312/Scripts/python.exe -m PyInstaller --noconfirm --onefile --windowed \
  --icon app_icon.ico --name "ObsCure汉化安装器_v1.00" \
  --distpath dist --workpath build --specpath . \
  --exclude-module unittest --exclude-module pydoc --exclude-module doctest \
  --exclude-module lib2to3 --exclude-module test --exclude-module numpy \
  --exclude-module PIL --exclude-module setuptools --exclude-module pip \
  --exclude-module email --exclude-module http --exclude-module xml \
  --exclude-module distutils installer_src/installer_diff.py
./inst_env312/Scripts/python.exe installer_src/append_payload_diff.py  # 追加 payload（只追加一次！）
# 四套测试
for t in verify_installer e2e_test e2e_vanilla_test gui_smoke; do \
  ./inst_env312/Scripts/python.exe installer_src/$t.py; done
```

> 坑1：append_payload 只能对**新鲜 PyInstaller 骨架**执行一次，重复追加会体积翻倍。  
> 坑2：managed Python 3.13 无 tkinter，GUI 版安装器必须用系统 Python312 构建。  
> 坑3：测试脚本里的 GAME/EXE/版本断言已按本机路径更新（源在 installer_src_v100/）。

## 5. 已知限制

| 项             | 说明                                |
| ------------- | --------------------------------- |
| 需要原版 datapack | 差分安装前提；缺失或 <100MB 明确报错            |
| 需 1.4GB 临时空间  | 解包产物，装完自动清理                       |
| 版本不匹配         | extract 失败 → 提示 Steam 验证完整性，原文件不动 |
| 游戏须关闭         | 覆盖 datapack 失败通常是游戏还在运行           |
| 别用最小化切屏       | 「最小化→还原」触发游戏原生白屏，请用 Alt-Tab       |
| 宽屏补丁冲突        | 异常时只勾汉化核心即可，不影响汉化                 |
