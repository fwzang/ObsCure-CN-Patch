# #3 乱码测试 · 傻瓜操作清单

> 你不需要懂任何技术。照着做就行。
> 目的：抓到「切场景后文字变乱码」那一次，好让 AI 知道问题出在哪一步。

---

## 一句话：你要做什么

**正常玩游戏，每次「换场景」就按一下对应的键。**

就这样。其他都是 AI 的事。

---

## 第一步：开两个东西

### 1. 打开游戏
正常启动 ObsCure，进主菜单即可。

### 2. 开一个"记录员"
新建一个终端窗口，复制粘贴这行命令回车：

```
cd /e/SteamLibrary/steamapps/common/Obscure
python hzp_tools/test3_watch.py
```

跑起来后你会看到类似：

```
热键就绪: F9   = P1 进入新场景
热键就绪: F10  = P2 返回暂停页
热键就绪: F11  = P3 返回主菜单
热键就绪: F2   = P4 离开房间再进入
记录器启动
```

**看到这个就行了 —— 然后切回游戏，不用再管这个窗口。**

---

## 第二步：玩游戏（重点）

**回到游戏窗口**（点一下游戏），然后正常玩。

每当你做了一个下面这些动作，**就按一下对应的键**：

| 你做了什么 | 按哪个键 |
|---|---|
| 进入一个新场景（比如从主菜单进游戏、走进一扇门到新区域） | **F9** |
| 游戏里按暂停（ESC 菜单）然后返回游戏 | **F10** |
| 退回主菜单 | **F11** |
| 从一个房间走到另一个房间 | **F2** |

> **按的时候游戏窗口是激活的，直接按就行**，不用切到别的窗口。按一下就完事，游戏不会卡。

### 建议路线（每条做 5 遍）

先读一个存档（比如 `02. 走廊（一层）`），然后：

1. 在走廊里走，进一个房间 → 出来（**F2** 或 **F9**）
2. 按 ESC 暂停 → 返回游戏（**F10**）
3. 退回主菜单 → 再读档进游戏（**F11** + **F9**）
4. 换个场景继续走，重复

大概玩 **30~40 分钟**就行。

---

## 第三步：如果看到乱码了（最重要！）

### 乱码长什么样？
文字变成看不懂的符号、竖条、或者碎块。

### 看到乱码时，按这个顺序做：

1. **先别动，等 5~10 秒**（让记录器多抓几帧）
2. **按一次暂停键进设置，再返回**（听说这样文字会恢复 —— 顺便验证一下）
3. **截图**（用 Steam 截图 F12，或者你习惯的方式）
4. **按一下 F9 打个标记**（告诉 AI"刚才乱了"）
5. 记一下：**是在哪个地点、做哪个动作时乱的**（比如"从走廊进教室时"）

然后继续玩，尽量多抓几次。

**如果一次都没乱** —— 那也是有用信息！说明这个 bug 不容易复现，AI 会换个思路。

---

## 第四步：结束

玩够了就：

1. 回到那个终端窗口，**按一下 ESC**（记录器会自己停）
2. 关掉游戏

然后告诉我一声「玩完了」，我来收文件分析。

---

## 你会得到什么

AI 会拿这三个东西去分析：

- `watch3.log` —— 你每次按键的时间点
- `x_hook.log` —— 游戏内部发生了什么
- 截图 —— 乱码长什么样

对比"乱的那次"和"没乱的那次"，就能找出问题。

---

## 常见问题

**Q：按 F9 游戏会卡吗？**
不会。它是后台热键，游戏感觉不到。

**Q：我按错了怎么办？**
没关系。多按一次而已，AI 能从截图判断实际情况。

**Q：一定要玩 30 分钟吗？**
不一定，抓到 1~2 次乱码就可以停了。

**Q：一次都没乱码怎么办？**
也告诉我。至少证明"当前版本在常规操作下没复现"，我会换个更狠的测法。
